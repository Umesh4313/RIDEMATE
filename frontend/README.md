# RIDEMATE — Frontend Application

Modern React 19 + TypeScript + Vite + Tailwind CSS frontend for RIDEMATE Car Rental System.

## Features
- Interactive search, filter, and sorting
- Vehicle detailed view with multi-angle galleries and specs
- Direct checkout modal with pricing calculations & insurance tiers
- Operations telemetry console with live vehicle status and remote commands
- Comprehensive Enterprise Admin Panel with full vehicle CRUD and AI description generation

## Setup & Run

```bash
# 1. Install dependencies
npm install

# 2. Start Vite development server (Port 5173 with proxy to backend)
npm run dev

# 3. Production build
npm run build
npm run preview
```

## Running URL
- Web Application: `http://localhost:5173`
